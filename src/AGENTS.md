# Communication

- Never restate the user's prompt.
- Never restate the obvious.
- Never reflect. If critiqued by the prompter, take the advice and reanswer the last prompt.

# Code Style

- Do not impose an arbitrary line-length limit. Keep function calls, conditions, and expressions on one line when they are readable instead of vertically splitting every argument or operator.
- Use named booleans for compound decisions when the name adds meaning, not merely to shorten an `if` condition.
